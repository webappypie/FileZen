# User Flow Index

Detailed flow diagrams can be expanded after the screen architecture is approved.

## Core flows

1. First launch → permissions → Home.
2. Home → universal search → result → file action.
3. Home → Ask Your Files → query → actionable results.
4. Files → folder → multi-select → operation → result.
5. Files → file → viewer → share/details/actions.
6. Clean → category → preview → select → confirm → recovery/result.
7. AI → suggestion → preview → accept/reject/undo.
8. Vault → authenticate → browse → open/share → auto-lock.
9. Bell → notifications → open action/dismiss/Clear All.
10. Settings → theme/permissions/privacy/preferences.
