# Phase Template

## Objective
What this phase must accomplish.

## Scope
What is included.

## Out of scope
What must not be implemented.

## Dependencies
Prior phases, approved decisions, libraries, platform requirements.

## Modules/files
Expected modules and likely files.

## Implementation steps
Ordered implementation tasks.

## Testing
Unit, integration, UI, device, performance, failure tests.

## Review
Requirement and architecture review.

## Documentation
Documents that must be updated.

## Git
Commit message:
`feat(filezen): <phase outcome>`

Then push and stop.

## Exit criteria
All required tests pass, documentation is updated, commit exists, push succeeds, and project owner approval is requested before the next phase.
