# Storage, Cleanup, Timeline and Vault

## Storage intelligence

Show total/used/free, category breakdown, folder breakdown, largest files/folders, recent growth, and locally tracked trends.

## Reviewable cleanup

Exact duplicates, duplicate/similar images, similar videos where practical, blurry photos, old screenshots, old APKs, repeated downloads, empty folders, large files, never-opened files, old recordings.

Never auto-delete user content.

## Destructive-action contract

Every cleanup action:
1. previews candidates;
2. shows item count;
3. shows size impact;
4. requests confirmation;
5. uses recovery/trash where feasible;
6. provides a result summary.

## Timeline

Browse today, yesterday, week, month, year, and creation/import/modification periods.

## Vault

PIN, biometrics, encryption, private previews, screenshot blocking where supported, auto-lock, hidden thumbnails, secure sharing workflow, privacy warnings.
