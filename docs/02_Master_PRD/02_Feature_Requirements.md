# Feature Requirements

## Priority model

- P0 — required for core product.
- P1 — required for V1 premium experience.
- P2 — planned expansion.
- P3 — experimental/future.

## P0
File browsing, file operations, permissions, local database, indexing, basic search, recent/favorites, media opening, basic document opening, offline behavior, crash-safe operations.

## P1
Universal search, OCR indexing, smart collections, AI rename, storage intelligence, cleanup review, Vault, advanced viewers, Ask Your Files, notification center, privacy-safe analytics, monetization.

## P2
SMB/FTP/SFTP/WebDAV, browser transfer, QR pairing, cloud file providers, deeper semantic indexing.

## P3
Advanced model capabilities, additional protocols, richer editing, experimental intelligence.

Every feature must map to:
- user flow;
- screen;
- domain module;
- repository/service;
- test suite;
- roadmap phase.
