# Media and Document Requirements

## Images

Target JPEG/JPG, PNG, WEBP, GIF, HEIF/HEIC, BMP, SVG, TIFF where feasible, and RAW where feasible through supported decoders.

Features: zoom, pan, rotate, slideshow, EXIF, metadata, OCR, share, basic crop/edit, image-to-PDF, format conversion, metadata removal.

## Video

Media3 is the primary Android playback layer. Target common containers/codecs including MP4, MKV, WebM, MOV, M4V, MPEG, and TS where supported. Support subtitles, subtitle delay, audio tracks, speed, PiP, background audio where permitted, gestures, resume, orientation lock, frame capture, playlists, and hardware acceleration.

## Audio

Common formats, background playback, notification controls, queue, folders/albums, speed, sleep timer, optional waveform, metadata.

## Documents

Target PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, TXT, CSV, Markdown, RTF, JSON, XML, HTML.

Initial priority: view, search, extract, share.

Unsupported formats must use a clear fallback: system handler, compatible installed app, or informative unsupported state.

## PDF Studio

View, search, bookmarks, annotations, highlights, signature, merge, split, reorder, page extraction, images-to-PDF, PDF-to-images, compression, password protection, OCR, scan, and local summary/extraction where supported.
