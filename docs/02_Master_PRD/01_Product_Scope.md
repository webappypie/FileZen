# Product Scope

## Product statement

FileZen is a next-generation Android file manager combining conventional file management with local-first intelligence.

## Scope

### Core
- File browser and folder navigation.
- Create, rename, copy, move, delete.
- Multi-select and batch operations.
- Sort/filter.
- Favorites/recent.
- Hidden files.
- Archives.
- Sharing/open-with.
- Metadata/properties/checksums.

### Intelligence
- Universal search.
- OCR and extracted text indexing.
- Smart collections.
- AI-assisted rename.
- Related files.
- Smart actions.
- Ask Your Files.

### Media/documents
- Image viewer.
- Video player.
- Audio player.
- Document viewer.
- PDF Studio.

### Storage/privacy
- Storage intelligence.
- Cleanup.
- Timeline.
- Vault.

### Later
- Network transfer.
- Cloud file sources.
- Expanded integrations.

## V1 non-goals

- Full office editing.
- Mandatory account.
- Server-side file storage.
- Mandatory cloud AI.
- Subscription paywall.
- Aggressive auto-delete.
- Claims of perfect AI understanding.
