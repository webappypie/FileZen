# File Management Requirements

## Sources

Support internal/shared storage, Downloads, media categories, documents, archives, APKs, SD cards, USB OTG, and user-selected SAF locations where Android permits.

## Operations

Create folder, copy, move, rename, delete, duplicate, share, open with, compress, extract, multi-select, select all, sort, filter, grid/list, bookmarks, file history, tabs, dual-pane on large screens, drag/drop where supported, batch rename, properties, checksums.

## Safety

- Copy/move operations must show progress.
- Long operations must be cancellable where feasible.
- Interrupted operations must leave storage in a recoverable state.
- Destructive operations require explicit user intent.
- Bulk operations must expose affected item count and estimated size.
- Errors must identify failed items without silently hiding partial failure.

## Searchable attributes

Name, extension, path, type, dates, size, metadata, EXIF, OCR, extracted text, tags, AI category, and supported semantic signals.
